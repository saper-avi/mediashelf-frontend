

# MediaShelf


## Описание 

**MediaShelf** - вебсайт, представляет из себя личную бибилиотеку выполняющая следующие функции:
    - Поиск фильмов по названию(через базу TMDB).
    - Открывать страницу фильма с информацией по фильму.
    - Добавлять фильм в свой список "Хочу посмотреть" или "просмотрено".
    - Ставить оценку фильмам и писать заметки к ним.
    - Ставить фильтры при просмотре своего списка фильмов.


## Технологии 

- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- Node.js + Express
- SQLite


## Установка

1. Клонировать репозиторий
2. Перейти в папку проекта
3. Установить зависимости: `npm install`
4. Создать `.env.local` на основе `.env.example` и заполнить переменные
5. Запустить: `npm run dev`
6. Открыть: http://localhost:3000
